# frontend

Aplikacja webowa systemu logistycznego – interfejs dla **dyspozytora** oraz **klienta / odbiorcy dostawy**.

## Za co odpowiada

- Planowanie tras: tworzenie i edycja planów, odcinków i postojów.
- Przydzielanie tras kierowcom.
- Mapa pojazdów z aktualną lokalizacją.
- Podgląd statusów przejazdów, ETA i opóźnień.
- Panel klienta: status własnej dostawy i przewidywany czas przyjazdu.

## Powiązane repozytoria

- [backend](https://github.com/Projekt-grupowy-2026/backend) – serwer i API, z którego korzysta aplikacja.
- [mobile-app](https://github.com/Projekt-grupowy-2026/mobile-app) – aplikacja mobilna dla kierowcy.
